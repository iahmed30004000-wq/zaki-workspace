# مجموعات المواضيع — Folder → Group → Topic

كل مساحة (space) بتقدر تقسّم مواضيعها لمجموعات، متل Telegram: **المجلد ← المجموعة ← المواضيع**.
المجموعة بترتّب بس: مين بيقرأ الموضوع بيضل تقرره صفوف الموضوع نفسها (`restricted` + أعضاء الموضوع).

## القواعد

- موضوع بمجموعة واحدة بالضبط، أو بدون مجموعة (بيظهر تحت «عام»). ما في نقل بيانات: كل المواضيع الموجودة بتضل بـ«عام».
- الإنشاء والتسمية والترتيب والنقل: أدمن المساحة والمالك.
- مجموعة **مقيّدة** (`restricted`): الصف تبعها بيظهر للمالك والأعضاء المذكورين بس (غيرهم 404). مواضيعها بتصير مواضيع مقيّدة لنفس الناس، فكل قواعد الدردشة (القائمة، البحث، التحويل…) بتنطبق بدون باب جديد. نقل موضوع **برّا** مجموعة مقيّدة ما بيفتحه لحدا.
- حذف مجموعة ما بيحذف أي موضوع ولا رسالة: بيرجعوا لـ«عام».
- غير المقروء بيتجمّع من الموضوع للمجموعة (`groups[].unread` بـ`/api/chat/home`).

## المسارات (كوكي المتصفح أو توكن «ميوز»)

| المسار | الشغل |
|---|---|
| `GET /api/groups?spaceId=` | مجموعات المساحة بالترتيب (`position`) |
| `POST /api/groups` `{ spaceId, name, emoji?, restricted?, memberIds?, position? }` | مجموعة جديدة (201) |
| `PATCH /api/groups/{id}` `{ name?, emoji?, position?, restricted?, memberIds? }` | تسمية، ترتيب، تقييد، أعضاء (بتتبعها مواضيعها) |
| `PUT /api/groups` `{ spaceId, order: [groupId…] }` | سحب المجموعات: `position` بيصير مكانها بالقائمة المبعوتة |
| `DELETE /api/groups/{id}` | حذف المجموعة؛ المواضيع لـ«عام» |
| `POST /api/groups/{id}/topics` `{ title, emoji?, topicType?, postingPolicy? }` | موضوع جديد جوّا المجموعة |
| `PATCH /api/topics/{id}` `{ groupId }` | نقل لمجموعة (`null` = «عام») |

بالتطبيق، `PATCH /api/topics/{id}` هو نفسه مسار إعدادات الموضوع (`/api/chat/topics/{id}`)، وبيقبل `groupId` مع باقي الحقول.
بالتوكن، بيقبل `groupId` **وبس** (ما بيغيّر عنوان ولا بيأرشف ولا بيحذف).

## «ميوز» (توكن النظام)

1. شغّل **«باب الربط الخارجي»** من الميزات.
2. **الإعدادات ← توكنات الأنظمة**: النظام **ميوز** (صلاحية وحدة: `chat.structure`)، اختار أي مساحة، «اعمل المفتاح»، وانسخه فورًا.
3. ما بيقرأ رسالة ولا بيكتب وحدة: ترتيب الدردشة بس. 60 طلب بالدقيقة.

```bash
TOKEN='zws_...'; URL=https://workspace.zakiai.io
# مجموعة
curl -s "$URL/api/groups" -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"spaceId":"<id المساحة>","name":"الإدارة","emoji":"🧭"}'
# نقل موضوع إلها
curl -s -X PATCH "$URL/api/topics/<id الموضوع>" -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"groupId":"<id المجموعة>"}'
```

كل عملية بتنكتب بسجل التدقيق (`chat.group.create` · `chat.group.update` · `chat.group.delete` · `chat.group.topic` · `chat.topic.group`) باسم صاحب المفتاح.

## أخطاء

`401` توكن غلط/ملغي · `403` ما عندك صلاحية (أو توكن لنظام تاني) · `404` مجموعة مش موجودة أو مش إلك أو مساحة تانية (أو «باب الربط» مطفي) · `422` اسم فاضي أو حقل غلط.

## الواجهة (موبايل أول)

- **داخل مساحة** (القائمة اللي فيها مواضيع المساحة): كل مجموعة صف واحد (صورة، اسم، آخر رسالة، مجموع غير المقروء من مواضيعها) و«عام» لمواضيع بدون مجموعة. الضغط بيفتح مواضيع المجموعة مع سهم رجوع. بدون أي مجموعة القائمة بتضل مسطّحة متل ما كانت. البحث والأرشيف وشاشة «كل الشركة» بتضل مسطّحة.
- **منتدى المساحة** (`/chat/s/<id>`): نفس الشي.
- **للمدير** (مالك أو أدمن المساحة): شريط رفيع فوق القائمة فيه «مجموعة جديدة» و«ترتيب» (سحب المجموعات من المقبض أو بالأسهم)، وجوّا المجموعة «ترتيب» لسحب مواضيعها (بتنحفظ كترتيبك الشخصي للمساحة)، وبقائمة صف الموضوع «نقل إلى مجموعة».
- **غير المقروء:** الموضوع ← المجموعة ← المجلد. عدّاد تبويب المجلد بيحسب المحادثات اللي فيها غير مقروء، فمجموعة وحدة بتزيد عدّاده بمحادثة وحدة لكل موضوع فيه غير مقروء.

# بوت فاذر والبوتات

مفتاح «الميزات»: `botFather` (مطفي افتراضيًا، بيعتمد على `apiDoor` و`doorMessages`).

## شو هو البوت
عضو مش بشري بالشركة: حساب لحاله (`User` بدون كلمة سر معروفة، ما بيفتح جلسة)، رتبته MEMBER، وبينضاف لمساحة وحدة (اللي كان فيها صاحبه). جدول `Bot` (إضافي بس) بيربطه بصاحبه وبرابطه.

## بوت فاذر
محادثة نظام لكل شخص ومساحة (موضوع مقيّد فيه الشخص لحاله، `dmKey = botfather|<userId>@<spaceId>`). مين يفتحها: المالك والمشرفين بس (`POST /api/chat/botfather`). كل رسالة بتنجاوب بسطر نظام `{k:"botfather", p:{text, reveal?, ask?, kb?}}`، بيترسم **فقاعة من بوت فاذر** وتحتها أزراره:

| الأمر | شو بيعمل |
|---|---|
| `/newbot الاسم @اسم_المستخدم` | بوت جديد؛ اسم المستخدم حروف صغيرة وأرقام و_ وبينتهي بـ`bot` |
| `/mybots` | بوتات الشركة |
| `/token @اسم` | توكن جديد، القديم بيموت |
| `/revoke @اسم` | إلغاء التوكن |
| `/setname @اسم الاسم الجديد` | اسم البوت (على حسابه وتوكنه الحي) |
| `/setdescription @اسم الوصف` | وصف؛ وبيظهر بصفحة البوت لحد ما تنحط نبذة |
| `/setabouttext @اسم النبذة` | نبذة صفحة البوت (لحد 120 حرف) |
| `/setjoingroups @اسم enable|disable` | هل بينضاف لمواضيع «ناس محددين» (والمجموعات المقيّدة) |
| `/setprivacy @اسم enable|disable` | وضع الخصوصية (تحت) |
| `/setcommands @اسم` + سطر لكل أمر | قائمة أوامر `/أمر - شرح` |
| `/setwebhook @اسم https://…` | رابط الرسائل (فاضي: إلغاء) |
| `/deletebot @اسم confirm` | حذف: التوكن بيموت، الحساب بيتعلّق، رسائله بتضل |
| `/setavatar @اسم` | البوت بيستنى صورتك الجاية بنفس المحادثة (10 دقايق، صورة وحدة، أقل من 2 ميغا، صورة عادية مش متحركة) وبتصير صورته؛ أي رسالة ثانية بتلغي الانتظار. |

**خطوة بخطوة (متل تيليجرام):** أي أمر بينقصه إشي **بيسأل** عنه، والرسالة الجاية هي الجواب: `/newbot` بيسأل عن الاسم وبعدين اسم المستخدم؛ الأمر بدون `@اسم` بيعرض بوتاتك أزرار (أو اكتب الاسم)؛ بدون قيمة بيسأل عنها. `/empty` بيمسح القيمة، `/cancel` بيلغي، وأي أمر تاني بياخد محل السؤال (إلا وقت طلب قائمة الأوامر، لأن سطورها بتبلّش بـ`/`). السؤال محفوظ بالسطر نفسه (`p.ask`) وبيعيش 10 دقايق، فما بيضيع بإعادة التشغيل. رسائل المحادثة الوحدة بتنعالج بالدور. `/setuserpic` هو `/setavatar`.

**الأزرار:** `p.kb`. الضغط `POST /api/chat/botfather/press {messageId, data}`: لصاحب المحادثة بس، وبس زر موجود على السطر فعلًا (غيره 404)، والمفتاح شغّال وصاحبه لسا مالك أو مشرف. أزرار القوائم **بتعيد رسم نفس السطر** (`message.edited`)، والزر اللي بيسأل بيضيف سطر جديد.

**الدخول:** صف «بوت فاذر» (بعلامة التوثيق) بـ«رسالة جديدة»، وبـ«جهات الاتصال»، وببحث قائمة الدردشة («بوت»، «فاذر»، «botfather»). بالمحادثة: «ابدأ» قبل أول رسالة، وبعدها «القائمة»، وكتابة `/` بتعرض الأوامر وشرحها.

**السر مرة وحدة:** التوكن وسرّ الـwebhook ما بينكتبوا بأي رسالة. السطر فيه علامة `reveal` وبيطلع زر «اعرض التوكن» اللي بيسأل `GET /api/chat/botfather/reveal/{id}` مرة وحدة (بالذاكرة 15 دقيقة، والسيرفر بينساه). بعد إعادة التشغيل: اكتب `/token`.

## وضع الخصوصية
شغّال (الأصل): ما بيوصل رابط البوت إلا اللي بيناديه والمحادثة الخاصة معه. مطفي: بيوصله كمان **كل** نص بموضوع **مقيّد** انضاف إله بالاسم. مواضيع المساحة المفتوحة بتضل بالمناداة بس بالحالتين، لأن ما حدا ضافه إلها.

## مش موجود من بوت تيليجرام
الوضع المضمّن (`/setinline`…)، الدفع، الألعاب، التطبيقات المصغّرة، نقل الملكية. والتوكن الكامل ما بينحفظ وما بينكتب برسالة (تيليجرام بيعرضه كرسالة).

## التوكن
`zws_…` بصلاحية `messages.write` بس، صاحبه (issuer) هو حساب البوت، فـ`POST /api/v2/messages` بينشر **باسم البوت** (وعلى الفقاعة اسمه). الباب بيقبله بس لو هو التوكن الحي لبوت حي (بدون `integrations.manage`)، ولازم «باب الربط» و«باب الرسائل» شغّالين.

## الـwebhook
الرسائل اللي بتنادي البوت (ذكر `@username`، أو أمر `/cmd`، أو محادثة خاصة معه) بتنبعت بـPOST واحد، 5 ثواني، بدون إعادة محاولة:

```
x-zaki-event: message
x-zaki-delivery: <uuid>
x-zaki-timestamp: <ثواني>
x-zaki-signature: sha256=HMAC_SHA256(secret, "<timestamp>.<body>")
{ event, delivery, bot:{username,name}, conversation:{id,kind,title,spaceId}, message:{id,text}, from:{id,name}, mentioned, command?:{name,args} }
```
الفشل بيطلع صف واحد تحت «التكاملات» بكود بس (`bot.webhook.http_500`, `bot.webhook.unreachable`, …).

## ميوز والميديا باير
بتضل بتوكناتها الحالية («توكنات الأنظمة»)؛ البوتات الجديدة بتنعمل من بوت فاذر.

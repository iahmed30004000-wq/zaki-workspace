The existing header query-count test (`chat-header.test.ts`) is green.
  9. **The switch `verifiedBadge`** (group «الدردشة», ON by default; name, hint, `FEATURE_META`, `ar.verified-badge.json`): off -> no `verified` anywhere (messages, rows, header, members, roster), the verify door answers 404 and the control disappears; the stored grants are kept and every mark comes back with the switch (tested both ways).

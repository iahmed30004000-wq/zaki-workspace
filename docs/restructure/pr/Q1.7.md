# Q1.7 — Customer data in the open chat: the hints

> Owner's decision (17/11): the team must be able to work with the customer's data in the chat. So this step is HINTS ONLY: nothing is blocked, hidden, masked
> or changed, there is no «خبّيها» button and no edit of a message. (The spec's moderator button «خبّيها من الموضوع» and the edit-to-masked-number are NOT built.)

## Definition of Done
- What must work: (1) a message shaped like the hand-typed order template (at least three labelled lines — name, phone, province, address, product, quantity… —
  one of them an identity label) gets, for its AUTHOR and the MODERATORS, «⚠️ هاي بيانات زبون — مكانها نظام الطلبات» with a line saying to enter it in the orders
  system; (2) a message with a phone-shaped number (not an order number, not a date, not a price) gets «🔧 حطّيها بتذكرة — بتنحفظ محمية» with one tap that opens
  the «🎫 مشكلة» form of Q1.5 with the number already in it, and the note that the message stays as it is in the owner's archive; (3) only in OPEN topics, only for
  text messages, not when a ticket was already made of the message; (4) the «الميزات» screen warns beside the three switches that send text to a model —
  «@المساعد», «ترجم», «بحث بالمعنى» — while automatic tickets are on; (5) the switch `orderTemplateHint`, OFF.
- Tests: `tests/customer-data-hint.test.ts` (7), `tests/db/customer-hints.test.ts` (3); must stay green: the whole suite.
- Edge cases that matter: «الكمية» and «السعر» alone are not a template; a date is not a phone; the text of a message is never changed.
- Blockers: CI red · an old test red · a secret exposed · a destructive migration (none).

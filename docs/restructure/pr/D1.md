## Definition of Done
- What must work: (1) two new themes plugged into the EXISTING theme engine (registry, palette, FX colours, the decoration table) — «سماء» (light) and «ليل أزرق»
  (dark), selectable beside the four old ones, which are untouched and stay selectable; (2) nine chat tokens in every theme (`bubble-out`, `bubble-out-fg`,
  `bubble-in`, `bubble-in-fg`, `chat-wallpaper`, `chat-pattern`, `selected-row`, `selected-row-fg`, `badge-muted`), with values for the four old themes too, so
  every theme renders the chat; (3) the contrast gate learns the chat pairs (own bubble, incoming bubble, selected row, the muted badge) and every one of the six
  palettes passes it; (4) the six wallpapers drawn in-house (`public/brand/wallpapers/`), credited as our own work; (5) the flat themes wear no decoration in the
  four places where decoration was allowed (plain identity): a `PLAIN` voice whose rules draw nothing; (6) `systemTheme()`, the tested helper for the default of a person who never chose a theme («ليل أزرق» / «سماء» by the device, or the old pair); it is NOT connected and has NO switch here (see the review below). `DEFAULT_THEME` does not change.
- Tests: `tests/design-v2-themes.test.ts` (9) and the updated pins of the theme tests (six themes, six radio cards, the token list, the plain voice); must stay green: all
  the theme, manifest and decoration tests, the whole suite.

- Blockers: CI red · an old test red · a secret exposed · a destructive migration (none).

## Independent review (read-only agent)
Real defects, each fixed (the testable ones with a failing test first): a `link` and a `fab` button were still sized by the `md:` classes on a wide screen (the compound variants now cancel them); the tonal button's `bg-accent/12` is a class Tailwind cannot build (it drew nothing; now `bg-accent/[0.08]`, hover `/10`, and a guard test lets the primitives use only opacity steps that exist); text inside a selected row on «ليل أزرق» was below 4.5:1 (that row's ground is darker now and the gate checks muted/accent/warn/danger on `selected-row` in every theme, plus the tonal hover); the switch `themeV2Default` was removed because nothing reads `systemTheme()` yet (turning it on would have done nothing: it comes back with the step that connects it); `Segmented` had no roving tab stop or arrow keys (one tab stop, arrows follow the reading direction, a focus ring); `ListRow` says `aria-current` when selected and its comment no longer promises an `as` prop; the time-of-day style gave «نهار» to a person on «ليل أزرق» (now «سماء»). The full suite also caught `:root {` in `globals.css` (a guard forbids it; it is `html {` now).
Recorded, not changed: the button heights at `md` and up are now 40 px (was 36) and `icon` is 40 px and round, with a focus ring — this is the design's own button set and reaches every screen that already uses `Button`, without a switch; the failed-address memory of the avatar lasts until a reload (a transient failure shows the initials until then).

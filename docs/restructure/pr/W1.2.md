    pinned on top of «المشاريع» with its own icon (an inbox tile, not an ordinary card), and is not listed a second time in the ordinary cards.

    `confirmPublic` enforced on the server): only WHERE it lands changed.
  - Existing hidden projects keep their ids and tasks; one that still wears the old default name «مهام فورية» takes the new name when it is next
    used (and is shown with it on the projects page); a name the owner chose is kept. Nothing is moved or deleted.

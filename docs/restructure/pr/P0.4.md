# P0.4 — Say who can see it

## Definition of Done
- What must work: a private conversation says so on screen and says who reads it. The head shows «🔒 خاص · 4 أشخاص»
  (restricted topic), «👥 للمقطع · 7 أشخاص» (a «مقطع»'s topic) or «🔒 بينكم بس» (a DM or a group) as a button that opens
  a sheet with the people and — honestly — «والمالك بصفة رقابة» when somebody outside the conversation holds silent
  oversight. An open topic shows nothing new. A restricted topic's row has a lock, a «مقطع» topic's row has the people icon.
  Before saving a topic's settings the screen says «رح يشوفه: …» with the list as it will be. The oversight banner reads
  «أنت عم تقرأ هالموضوع بصفة رقابة — أصحابه ما بيعرفوا إنك قرأت».
- Tests: `tests/chat-privacy-render.test.ts` (new, render tests for the four states, the sheet, the rows, the settings line,
  the banner), `tests/db/chat-privacy-notice.test.ts` (new, 4 cases: the server's `oversightNotice` for a DM / restricted /
  «مقطع» topic, absent for an open topic, false when the only holder is one of the people, follows the permission not the
  rank). Must stay green: `tests/arabic-ui.test.ts` (Arabic, Western digits), `tests/encoding-hygiene.test.ts`, the chat home
  render tests.
- Edge cases that matter: the notice is computed on the server from the same rule as `holdsArchiveView`
  (`oversightReaderExists`), never guessed by the screen; it is absent for an open topic; a partner whose `archive.view`
  was taken away is not counted (P0.1); a «مقطع»'s topic with no member rows counts its audience (`mentionables`).
- Blockers: CI red · an old test red · a secret exposed · a destructive migration (none: no schema change).

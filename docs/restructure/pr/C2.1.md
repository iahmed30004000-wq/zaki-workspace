## Independent review
There is no tool in this worker session to start a separate agent, so the review was the `code-review` skill run on the committed branch (a forked, read-only pass that read the diff and ran nothing). Its first two runs returned nothing usable (it was attached to the wrong repository, then answered with an empty result); the third returned 10 findings, each judged here:
- **Real, fixed:** (1) the «⋮» trigger was `display: none` on a phone, so a long press anchored the menu at the top corner of the screen: it now always has a box (absolute at the row's end, invisible and not clickable on a phone; in the row on the computer). (2) The forum overlay (z-40) covered the column's resize handle (z-30): the handle is z-50. (3) ↑ / ↓ moved the focus to the next row even from the «⋮» button (taking the arrows from its menu): the handler now acts only from a row's own link. (4) The column subscribed to the forum's whole list just to know whether an open conversation is one of its topics and re-drew on every message: one yes / no question of the cache now (`useForumHolds`, `nextForumSpace` takes it). (5) A DELETED voice note showed «رسالة صوتية» (the check for the voice kind came before the deleted check): the null preview, which the server sends for a deleted message of any kind, is judged first (the body column is never null, so a live voice note has an empty preview). (6) A failed refresh over a list that already holds rows (the start copy) was silent: it shows the alert and the retry above the rows. (8) The virtualizer is told to measure again when the row height changes. (9) The row's time label never rolled over at midnight: one `dayKey` of the list re-draws the (memoized) rows once a day.
- **Answered without a change:** (7) `forumRows` and `forumItems` both split live from archived: cheap, and each is pinned on its own by its own tests. (10) The layout and the pages each ask `isFeatureOn`: all of them share ONE read per render (`orgSummaryOf` is `perRequest`), so they cannot disagree inside a request and add no query.

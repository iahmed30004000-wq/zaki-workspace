# Q1.0 — The link to the orders system

## Definition of Done
- What must work: (1) an integration kind `OMS` (its enum value alone in its own migration folder) and `Card.external JSONB NULL`
  (additive); (2) a client with three calls — products, an order's state, a note on an order — a bearer token, the base URL judged by
  the SSRF guard on every call (public https only), 5 seconds, no redirects, a failure written as a FAILED event holding a code only,
  never the token, never a response body; (3) a sync every 5 minutes (counted from the last attempt, failures included) that rewrites
  the snapshot of each ALREADY linked sheet in `Card.external` and nothing else: no revision, no version, `updatedAt` unchanged, never
  deletes or creates a sheet, an id beats a code, two products with one code link nothing by themselves, a product that is gone marks its
  sheet (and comes back clean), an empty answer marks nothing; (4) the owner's card under «التكاملات»: address, token (write-only,
  encrypted), the day it ends with a warning 14 days before, «اقرأي هلّق», the last failure as a sentence for its code; (5) the stale
  rule as a pure helper (older than 30 minutes = stale; a future date is not); (6) the ONE ordered prompt for the orders system;
  (7) the switch `omsLink`, OFF.
- Tests: `tests/oms-snapshot.test.ts` (14, new), `tests/oms-client.test.ts` (11, new), `tests/oms-link-card.test.ts` (6, new),
  `tests/db/oms-sync.test.ts` (30, new); must stay green: `tests/features.test.ts`, `tests/db/features.test.ts`, the whole suite.
- Contract test: against `tests/fixtures/oms-products.provisional.json` — PROVISIONAL, written from the spec, not copied from the
  orders system; the real example replaces it once the owner brings `contracts/oms-workspace.v1/`.
- Edge cases that matter: the token is never in an answer, an event, a log line or an error, even when the other side echoes it; the
  base URL keeps its origin only; `lastSyncAt` moves only on a good read; a company's sync never touches another's sheets.
- Blockers: CI red · an old test red · a secret exposed · a destructive migration (none).

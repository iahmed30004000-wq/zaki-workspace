# S5.4 — The conversation profile: a tappable header, tabs that are always there, every link (switch `chatLayoutV2`, existing; no new switch, no schema, no migration)

## Definition of Done
- What must work: (1) **The whole identity block of the pane header opens the info panel**: the picture, the name and the line under it are one block with ONE button stretched over all of it (`data-header-identity` / `data-header-title`, `aria-label` «افتح معلومات «الاسم»», `aria-expanded`). The lock chip («🔒 خاص · 4 أشخاص») stays its own button above it (it opens its sheet), so no button holds another; the search, call and «⋮» buttons are untouched. (2) **The panel's tabs are always drawn**: «الوسائط · الملفات · الروابط · الصوتيات» and, for a topic or a group, «الأعضاء»; each says in its own sentence when there is nothing (a count of zero asks the server for nothing and says it at once; a count not known yet says «عم نحمّل…», never «empty» from a guess). The old «الشغل» and «المثبّتة» stay and are drawn only with data. The default tab is the chosen one, else the first content tab that has something, else «الوسائط». The strip is a wrapping row of pills (no horizontal scroll). (3) **«الروابط» lists EVERY web address found in the messages** (`GET …/media?kind=LINK`): the chat's one tokenizer (`lib/chat/format/links.ts`, so `www.…` and the address inside `[text](address)` count; `mailto:`, `javascript:`, `ftp:` and addresses with a user name do not), every address of a message (not only the first), newest first, one row per page (the host's case, a trailing slash and a `#fragment` do not make a new address), with the **host**, and the card's title/picture only from an OK preview made for THAT address while the preview switches are on. The count of the tab is the number of those addresses among the 1000 newest link-bearing messages. Never an address of a deleted message (the owner too), a system line, another conversation, or a conversation the reader may not open (404); the silent eye writes nothing. (4) **«الوسائط» is a grid of thumbnails**: a picture is its own image; a video tile is a FRAME of the video (`<video preload="metadata" src="…#t=0.1" muted>`: a range request for the start of the file, never autoplay, never the whole file), a play mark, and its length (`1:15`). The film icon stays under the frame as the fallback. (5) **A mute row** («كتم الإشعارات») with the EXISTING five presets (`MUTE_PRESETS` / `mutedUntilOf` from `row-preview.ts`, through the row menu's own hook `usePersonalCall` → `PUT …/me`); while muted: «الإشعارات مكتومة» and «رفع الكتم». Not drawn for «الرسائل المحفوظة», for a reader in silent oversight, or while the company's `chatPersonalState` is off (read from the list the cache holds). (6) **Members tab**: an OPEN topic lists its whole audience as the existing detail door gave it (`mentionables`, the assistant left out); a RESTRICTED topic lists the door's own `members` only (never `mentionables`) and nobody when the door gave nothing; a topic of a SECTION never lists (the door's lists are the space's): the count only; a group lists its rows; a private chat has no members tab. (7) **Privacy pinned**: a restricted topic's names reach its people only (an outsider gets 404 and no name; the owner follows the existing oversight rule).

## Independent review
A read-only review of the staged diff (`/code-review`, medium; it ran no test) found ten things. Seven are real and fixed, six of them with a failing test first (the seven source pins at the end of `chat-v2-composer-seam`, the three model tests of the review at the end of `chat-v2-composer-model`; all were run red, the import or the assertion failing, before the fix):
1. **The paste dialog replaced the tray** and the typed body, so files already attached were lost unsent, and a paste while an upload ran left the images stuck in the tray. Now the pasted pictures are ADDED to the tray, and a paste while busy changes nothing.
2. **The paste dialog sent with the stale `clientId`** (it renewed the state and then sent with the closure's old id), so a retry after a lost answer could have been a second message with the outbox off. `sendNow` now takes the id it is sent with.
3. **A drag of files over a pane that was busy, editing or recording was the browser's**, which opens the file and leaves the page (the draft and the recording lost). The listeners now stay; only the two zones are not drawn.
4. **A stuck «touch» flag could eat the first keyboard click on the microphone** after a hold on a hybrid device. Replaced by a timestamp (a click within 0.8 s of a touch is the hold's own).
5. **The hold followed any pointer**: a second finger could send the note early or start a second recorder. It now follows the one pointer that went down and ignores a second pointerdown while a hold is open.
6. **Enter did not send a file with no caption** (the round button did). Both use `canSubmitNow` now.
7. **A raw «Failed to fetch» could reach the screen** (the old composer's rule, copied). `failMessageOf`: a dictionary key is translated, an Arabic sentence is shown, anything else is the fallback sentence.
Also taken: `saveEdit` is guarded by `busy` (a double Enter sent two edits); a pasted file that is not a picture (a PDF) now goes to the tray as a plain file; the emoji CDN (see Owner actions: our own data now). Not taken: a paste that carries BOTH words and a picture stays a text paste (a cell copied from a sheet carries both; the picture is not lost from the clipboard, only not offered): said in the tests.

# Pull-request files

One file per branch, named after the branch's first step: `P0.1.md`, `F0.md`, `Q1.0.md`, … Each is written BEFORE the
change (the Definition of Done first), finished before the step is closed, and committed on its own branch.

The template is in `docs/restructure/BUILD-PROMPTS.md` §10. The independent review of a phase is written here too, as
`<PHASE>-review.md`.

Nothing here is a secret or customer data: the repository is public.

# W1.9 — «مهام قديمة»: the review list of old tasks and the «آلي» mark (`workStaleSweep`, OFF)

## Definition of Done
- What must work:
  1. **The list.** `/my-work/stale` (and `GET /api/work/stale?days=&auto=&space=`) lists the OPEN tasks (not finished, not archived) that nobody touched for N days (default 14, 1 to 365): no edit of the row, no comment and no log line inside the window. Grouped by PERSON (the busiest first, «بدون مسؤول» under its own heading), then by PROJECT, the longest-untouched task first. A space filter for the owner.
  2. **Who sees it.** The OWNER (all spaces of the company) and anybody who MANAGES a space (its ADMIN, an org ADMIN who is in it: `isSpaceManager`); the list holds the tasks of the spaces the person manages. A guest: 403 `guest.no_access`; everybody else: 403 `stale.managers_only`; the page shows the same two sentences. Archived spaces are not listed.
  3. **P0.2.** Every read goes through `taskVisibleWhere`: a hidden task is neither listed nor counted (not in the totals, not in the «open per person» numbers, not named anywhere in the answer). The owner without silent oversight does not read a private task of a space either (P0.1).
  4. **Four bulk actions, through the existing services only:** «سكّريها» = `moveTask` into the board's first done column; «عيّني مسؤول» = `updateTask({ assigneeId })` (the same two checks the task's own PATCH makes first: an ACTIVE member, a member of the project's team; the assignee is told); «أجّليها لتاريخ» = `updateTask({ dueDate })` (noon of the day in the company's zone, never a day before today); «أرشفيها» = `updateTask({ archived: true })` (the existing flag: NOTHING is deleted).
  5. **Judged PER TASK, never all or nothing.** Each id is read again through the visibility rule and answered on its own: `done`, `requested` or `refused` with a machine key. Refusals: `task.not_found` (hidden, another company, no such task: the same answer), `stale.not_manager` (visible, but in a space the person does not manage), `stale.not_open` (finished or archived meanwhile), and whatever the service itself says (`reward.owner_only`, `section.edit_denied`, `board.no_done_column`, `assignee.not_member`, `assignee.not_active`, `assignee.not_in_team`, `taskreq.already_pending`, the project's required fields). A mistake of the call itself (no tasks, more than 200, no/past day, no person, unknown action) is a 422 before anything happens.
  6. **No rank bypass.** A person of a HIGHER rank than the manager is ASKED, never given the task: `updateTask` makes the request and tells them, the task keeps its holder, the answer says `requested` (the screen words it). A reward task is the owner's: closing or archiving it is refused for anybody else (`reward.owner_only`).
  7. **Every change is a log line.** Each task that changed gets a `task.stale_swept` `TaskActivity` line (`{ action, outcome, from/to, day }`), besides the line the service itself writes (`updateTask` writes none for an archive); one `task.stale_sweep` audit row per call. A refused task gets no line (nothing happened).
  8. **«آلي» (D-W4, PENDING — the recommended default).** A task with `Task.apiTokenId` set carries a small «آلي» mark (`AutoMark`; `RowTask.automated` in `task-row.tsx`, and in the list), is counted APART (`open` = the person's own work, `openAuto` beside it; `autoTotal`), and the filter «الكل · بدون الآلي · الآلي بس» (default «الكل») can hide it or show it alone. On screen: «فصل الآلي عن شغل الناس بانتظار قرار المالك».
  9. **Switch** `workStaleSweep`, default OFF (`features.ts`, the two Arabic lines, `tests/features.test.ts`). Off: the route answers 404 for everybody, the page is not found; no table, row or screen changes.
- Tests: `tests/db/work-stale-sweep.test.ts` (new, 23), `tests/db/privacy-matrix.test.ts` (+3: the list as one more surface of the owner's table), `tests/features.test.ts` (+1 and the pinned lists), `tests/db/features.test.ts` (the one-token pin).
- Edge cases that matter: a recent comment or log line is a touch; a task made through a door has a log line from today; a private task for a partner without oversight; a task of another company; a space where the manager is only a member; a task finished while the list was open; the same id twice; a reward task; a person who lost the «المهام» box; a board with no done column; an assignee suspended or from another company; an `auto` value that is nonsense.

## Switches
`workStaleSweep` — default OFF — OFF: no page, the route answers 404; ON: the list for the owner and the space managers. Nothing it shows is stored by it; what a sweep did stays (a log line per task, the archived flag can be undone).

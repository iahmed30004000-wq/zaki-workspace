## Decisions I took (and why) — the owner may change any of them
1. **The chat group comes first, not third.** The spec lists the groups as work · library · chat · …, but C4.3's pinned tests (`tests/company-chat-settings.test.ts`, must stay green) require the chat group to head the list. The other five keep the spec's order.
2. **«كل شي» = every switch that is ON in an untouched company, set ON** (so it brings back the ten of the simple mode and whatever the owner switched off by hand). It does NOT switch on a switch that starts OFF: the ones that send text to a model, the backup, the outside door, economy mode («وضع التوفير» would turn things OFF), the owner-hiding switch, and the rollout switches awaiting the owner's own check. A button must not do that; they are turned on one at a time. The preset's description says so. If the owner meant the literal «everything», it is one line (`presetTarget`).
3. **A child that is already ON is not locked.** «Disabled while its parent is off» is applied to switching it ON; one that is ON with a parent off shows «بيحتاج: …» and can still be switched off, so the owner is never trapped.
4. **No new ⚠️/🔧 strings for other switches.** Their hints already carry ⚠️ and 🔧 inline (`dbBackup`, `apiDoor`, `omsLink` … checked by a script over the dictionary), and C4.3 shows its five as separate lines; the hint stays one piece of text because C4.3's tests pin the whole hint in the markup. Nothing is split or removed.

# P0.3 — Work made from a private conversation stays private

## Definition of Done
- What must work: «اعمل منها مهمة» / «تذكرة» from a DM, a group, a restricted topic or a team's topic, and an idea or a
  project made from a comment of a watching session (a restricted topic). A TASK is «المعنيين بس» by default; making it
  «المساحة كلها» needs an explicit choice AND `confirmPublic: true`. A TICKET (read by its department) and an IDEA or a
  PROJECT from such a source need `confirmPublic: true`. Without it the server answers 400 `work.confirm_public_required`
  and nothing is created. From an OPEN topic nothing changes. The dialog explains (⚠️ + 🔧) and asks; the SERVER decides.
- Tests: `tests/db/private-chat-work.test.ts` (new, 6 cases: task default, public only with the confirmation, DM, team
  topic, open topic unchanged, ticket), `tests/db/watch-convert-links.test.ts` (extended: unconfirmed idea/project refused,
  confirmed ones made, the colleague no longer sees the task made from a private comment). Must stay green: the whole suite,
  `message-to-work`, `watch-convert`.
- Edge cases that matter: one place decides what a private source is (`sourceOf` in `make-work.ts`: not a TOPIC, or
  restricted, or a team's); `confirmPublic` alone changes nothing (a task without the explicit «للمساحة كلها» stays private);
  the refusal comes before anything is written.
- Blockers: CI red · an old test red · a secret exposed · a destructive migration (none: no schema change).

## What changed
- `make-work.ts`: `sourceOf` returns `privateSource`; `assertConfirmed` is the one rule; `makeTask` takes `visibility` and
  `confirmPublic` and defaults a private source to `PARTICIPANTS`; `makeTicket` needs `confirmPublic` from a private source.
- Routes: `chat/messages/[id]/task` accepts `visibility` and `confirmPublic`; `…/ticket` accepts `confirmPublic`;
  `ideas` and `projects` accept `confirmPublic`; `watch/convert.ts` `assertWatchComment` refuses an unconfirmed private source.
- Dialog (`make-work-dialog.tsx`): prop `privateSource`; a checkbox «خليها للمساحة كلها» (a ticket cannot be sent without it),
  ⚠️ + 🔧 when ticked, and a line saying the task will be «للمعنيين بس» when not. The chat screen passes it for a DM, a
  group, a restricted or a team's topic; the watch comments always do, and asking before an idea or a project is made from
  a comment (`window.confirm`, the same words).
- Strings in `ar.task-privacy.json`: `work.confirm_public_required`, `taskpriv.from_private_warn`, `…from_private_fix`,
  `…make_public`, `…private_default`.

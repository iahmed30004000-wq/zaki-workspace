## Independent review (read-only agent)
Real defects, each fixed (the testable ones with a failing test first):
- «اطلع من كل الأجهزة» ended the cookies but left the person's browsers (`PushSubscription`) and paired phones (`AppDevice`) receiving their notifications: the route now deletes the caller's OWN rows in the same transaction (test: only the caller's, an admin's stay), and the screen's ⚠️ says so.
- A failed read of the prefs could stop a ring or a notification for EVERYBODY: both reads (`withCallsOn`, `prefsOf`) now fail open (everybody is told, as before this step) and log.
- «one emoji» was only «starts with an emoji»: `isOneEmoji` now counts graphemes (`Intl.Segmenter`: a flag, a family and a skin tone are one, two emojis side by side are two).
- A private chat that names the person was classed «mentions», so switching «الإشارات» off silenced a private chat the person kept on: a private chat is now always «الخاص» (test in `notify-prefs`).
- Two quick changes (or a change from another tab) were each computed from the screen's last draw and the second replaced the first: the screens now BUILD the patch from the prefs in the cache at the moment of the save (`useSavePatch((current) => patch)`).
- The device's copy of an account's choices stayed in the browser after sign-out: `clearMirror()` runs in the avatar menu's sign-out and in «اطلع من كل الأجهزة» (the device's own choices stay).
- «المواضيع» also covers the old groups: its line now says so.
Recorded, not changed: with the preview off the push TITLE still names the chat or the sender (the spec's «رسالة جديدة» only is the body; Telegram does the same) and the link still opens the message; «افصل» for a browser removes the server's row, but that browser's own push subscription stays and re-subscribes by itself the next time it opens the app (push-client.ts), so it can reappear; with the switch ON and no theme cookie the flat pair applies unless the account says «تلقائي» is not wanted — the account never stores «false» (the key is removed), so «not auto» on a device with no cookie means «follow the company default».
